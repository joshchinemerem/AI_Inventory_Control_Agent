# Submission Checklist

## Required deliverables
- [ ] Complete solution code
- [ ] Agent instructions/prompts
- [ ] README
- [ ] Improvement Changelog
- [ ] Reproduction Guide
- [ ] Evaluation results
- [ ] ≤5-minute solution video
- [ ] Representative trajectory for every agent

## Quality checks
- [ ] Clear intended user
- [ ] Clear bottleneck
- [ ] Clear value
- [ ] Baseline is simple and fair
- [ ] Baseline and final use the same evaluation cases
- [ ] 10+ cases where practical
- [ ] At least one challenging case
- [ ] Primary metric defined before evaluation
- [ ] Every claimed result has evidence
- [ ] Failures are included, not hidden
- [ ] Human approval is present before consequential actions
- [ ] No private credentials in repository
- [ ] Only approved/public/synthetic data used
- [ ] Another person can run the project from a clean environment
